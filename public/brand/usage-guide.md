# Reshi Resume Studio · Exact Fit

Approved direction: B. Two fitted shapes evoke a source résumé and its tailored
version without depicting a document. Retain the curved channel and orientation.

## Colour variants

- Indigo `#5145CD` (RGB 81, 69, 205): primary mark on white or warm-white.
- Black `#000000`: single-colour print and neutral light backgrounds.
- White `#FFFFFF`: indigo or dark backgrounds; never place on white.
- Ink `#24262B`: accompanying brand-name text.

White/indigo contrast is approximately 6.8:1; the shape remains meaningful
without colour. RGB is the digital master. Print conversion and spot-colour
matching require proofing; no Pantone match is asserted.

Use Segoe UI Bold for the brand name and Segoe UI Semibold for the descriptor.
Do not distribute Windows font software. UI text uses locally installed fonts
and an Arial fallback; standalone logo lockups use outlined lettering.

## Size and spacing

- Standalone symbol: minimum 16 px canvas. Recommended 24 px or larger.
- Leave at least 24 units of clear space around the visible mark on its
  256-unit canvas. The supplied app icon already includes its clear space.
- Keep the white fitting channel open; never stretch, rotate, add a gradient,
  add outlines, or colour the pieces independently.
- Use only the symbol for favicons. Never squeeze the full name into an icon.
- Full-name lockup: recommended minimum 200 px wide; use live accessible text
  alongside the symbol in the application.

SVG and transparent PNG variants are included. Browser and Apple touch icons
use a white symbol on indigo. The website uses the same approved geometry in
its sidebar, loading state and compact mobile/collapsed-sidebar header.

The mark is not trademark-cleared. Obtain a trademark/reverse-image search
before a public commercial launch.
